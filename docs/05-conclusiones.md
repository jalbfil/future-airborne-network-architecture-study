# 05. Conclusiones

El aprendizaje principal del estudio es:

> Una arquitectura de comunicaciones futura debe diseñarse alrededor de la continuidad de información de misión, no solo alrededor de la conectividad.

El simulador demuestra que una red puede estar parcialmente disponible, pero no necesariamente soportar todos los servicios. También muestra que una misión puede seguir siendo viable si se preservan flujos críticos y se degradan de forma controlada los no esenciales.

Ideas clave:

- no todos los datos tienen el mismo valor;
- el ancho de banda debe asignarse según prioridad;
- SATCOM puede sostener lo esencial, pero no tráfico pesado;
- el relay puede recuperar continuidad cuando falla el enlace directo;
- el edge ayuda a reducir carga antes de transmitir;
- la visualización debe mostrar estado de misión, no solo estado de enlace.

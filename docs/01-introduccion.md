# 01. Introducción

Este repositorio estudia una cuestión central para las comunicaciones futuras en entornos aerotransportados:

> ¿Cómo diseñar una red de misión que mantenga los flujos de información críticos cuando los enlaces se degradan, se limitan o cambian dinámicamente?

El enfoque no parte de una plataforma concreta, sino de una idea más amplia: las futuras arquitecturas aéreas tenderán a comportarse como **sistemas de sistemas**, donde nodos tripulados, no tripulados, estaciones terrestres, enlaces SATCOM, servicios edge y pasarelas federadas intercambian información de misión.

La red deja de ser un simple transporte de paquetes y pasa a ser una capa de continuidad operativa. Por eso, el proyecto no se limita a preguntar si hay conectividad, sino qué flujos sobreviven en cada escenario.

## Alcance

Este estudio es conceptual, público y educativo.

No representa una arquitectura oficial, no reproduce ningún programa concreto y no contiene información sensible. El objetivo es construir criterio técnico sobre nodos de misión, tipos de enlace, clases de tráfico, priorización, resiliencia, interoperabilidad y visualización de continuidad.
